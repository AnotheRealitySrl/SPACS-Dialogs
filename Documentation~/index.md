# SPACS-Dialogs

## How to install

Import from Git URL using Unity Package Manager: `https://github.com/AnotheRealitySrl/SPACS-Dialogs.git`

Alternatively, if you need to modify the content of the package, import it as a submodule under the `Packages` folder.

Dependencies:

- `com.anotherealitysrl.spacs-graphs` (brings `com.anotherealitysrl.spacs-utility`)
